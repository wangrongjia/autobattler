## 1. 模式总纲

### 1.1 命名、入口与解锁

| 项 | 方案 |
|---|---|
| 模式名 | **∞ 无尽远征**（系统内部 `game_mode == "endless"`） |
| 入口 | 「战 斗」面板新增模式卡：副标题「15 回合完成首征，此后每 5 回合一个据点」；显示历史最高回合 / 最高军势等级 / 进行中存档；按钮：开始新远征 / 继续远征 / 查看纪录 |
| 解锁 | 通关任意难度第 20 关「天下归一战」 |

### 1.2 回合流程

```
每回合：整备(经济/军情) → [天书(按日程)] → 选将×3 → 布阵(天书阁/军府) → 30 秒战斗 → 回合结算
每 5 回合(据点)：锁定奖励 → 军势公示 → 战策三选一 → 军府整备 → [第15回合起] 凯旋结算 或 继续远征
每10回合(统帅回合)：额外战场事件，胜利奖励更高
```

★ **选将全程 3 次/回合，永不降频**；★ **无尽备战区 18 格**（普通闯关维持 9 格，接口化 `_run_reserve_limit()`）。理由：敌方持续增强、双方阵亡加剧，高频补员本身就是无尽后期的主要操作与策略空间；备战翻倍让「囤同名/混编/轮换」成为可行打法。

### 1.3 胜负规则（含破阵判定细则）

| 事件 | 结果 |
|---|---|
| 玩家主公归零 | 远征结束，结算到**上一个已锁定据点** |
| **敌方主公归零（破阵）** | **本回合提前胜利——无论敌方武将是否仍在场（斩首战术成立）**：破阵瞬间全场战斗立即结束、存活敌将不再行动；奖励 = 额外将魂 `100+20×C`、下回合全军 +20 初始行动条、军府 8 折券一张 |
| 30 秒结束且玩家主公存活 | 守住本回合 |
| 每个新回合 | 敌方主公**满血重入**且按 §2.1 主公式成长——「永远杀不完」即无尽生命的落地形式 |

### 1.4 据点与奖励锁定

第 5/10 回合只锁将魂；第 15 回合**首次远征完成**（开始掉将印 + 凯旋/继续）；此后每 5 回合锁定新奖励；非据点回合战败保留最近据点奖励；退出游戏回到本回合整备快照；破纪录额外 +2 枚将印（每局一次）。

## 2. 敌方强化路径（完整）

### 2.1 统一深度与数值曲线（★ v0.4 双调整）

定义：`R`=回合；`D=R-1`；`C=floor((R-1)/5)`。

| 项目 | 公式（v0.4） | 相对 v0.3 | 接入点 |
|---|---|---|---|
| 敌将生命倍率 | `1.75 × 1.065^D × (1 + 0.08×C)`，上限 ×200 | **放缓**（原 1.07^D×0.10C）| `_challenge_enemy_hp_multiplier` endless 分支（`progression_system.gd:173`） |
| 敌方兵略加成 | `100 + 6×D + 15×C`，上限 +2000 | 不变 | `_challenge_strategy_bonus`（:163） |
| 敌方行动增速 | `1 + min(0.35, 0.02×C)` | 不变 | `_unit_action_gain_multiplier`（`combat_system.gd:467`） |
| 敌方主公生命倍率 | `1.6 × 1.095^D × (1 + 0.14×C)`，上限 ×400 | **加陡**（原 1.5×1.09^D×0.12C）| 每回合整备重设主公 HP |
| 控制抗性/减伤 | 只由军势与事件提供 | 不变 | — |

> **放缓理由（拍板 #7）**：董卓（按当前生命）、孙坚（消耗当前生命）、黄盖（消耗最大生命）、孙权（最大生命成长）这类「生命转化伤害」型敌方单位，其伤害随生命倍率水涨船高——倍率增速过快会让这些敌将变成数值黑洞。放缓后仍保持远高于玩家生命成长（玩家生命来源近乎恒定，敌方 50 回合仍达 ~65 倍）。
> **备选技术方案（不默认启用）**：生命转化类技能改为按**基础生命**（非倍率后生命）计算转化值，可彻底切除该耦合——列入实现时的观察项，若模拟显示董卓/黄盖系敌将 DPS 失衡再启用。

## 4. 将印系统（★ v0.4 数值规则全面修订）

### 4.1 资源与掉落（★ 公式随树加深上调）

| 资源 | 用途 |
|---|---|
| 通用将印 | 点亮任意武将树（通用节点与定位/绝技/长青层） |
| 专属将印 | 点亮该武将树全部节点（含分歧、羁绊、将魂层） |

**掉落**（第 15 回合起，每据点，恒偶数严格五五分）：

```
本据点将印 = 2 + 2 × floor((据点序号 - 3) / 3)
  据点3~5（回合15/20/25）= 2 枚   据点6~8（回合30/35/40）= 4 枚   据点9+（回合45+）= 6 枚
破纪录（终局刷新个人最高回合）= 额外 2 枚（通用1+专属1，每局一次）
```

将魂：`本据点将魂 = 1000 + 500 × 据点序号`；破阵另加 `100 + 20×C`。

### 4.2 贡献度（同 v0.3）

`原始贡献 = 输出 + 承伤 + (治疗+护盾)÷0.6 + 控制秒数×折算 + 增益`；`最终权重 = 75%×贡献占比 + 25%×参战回合占比`；`抽取权重 = 85%×最终权重 + 15%÷合格武将数`；hero_id 聚合、需真实上阵、run_seed 防刷、据点原子写入。

### 4.3 树结构（★ 5 层 → 7 层，双层多选）

| 层 | 节点 | 级数 | 选择规则 | 内容 |
|---|---|---|---|---|
| 一 · 根基 | 3 | 各 3 | 全部可点 | 生命% / 兵略% / 疾行（冷却%，到顶转行动增速） |
| 二 · 定位 | 3 | 各 2 | **3 选 2** | 角色职责强化（点哪两个决定打法底色） |
| 三 · 绝技 | 3 | 各 1~2 | **3 选 2** | 技能机制改造（同层互斥感：选了 A+B 就没有 C） |
| 四 · 分歧 | 2 | 1 | **2 选 1（互斥）** | 构筑方向定型，换向需重置 |
| 五 · 羁绊 | 1 | 2 | — | 强化该武将参与的**真实**组合羁绊；无组合羁绊者强化阵营羁绊 |
| 六 · 长青 | 1 | 2 | — | **持续成长**：随战斗时长/整局回合数无限成长，适配无尽后期 |
| 七 · 将魂 | 1 | 1 | — | 改变技能规则的终极能力 |

**根基数值规则（★ 拍板 #6，全部改为乘区式）**：

- **生命**：以「基础生命 + 天赋 + 符文」之后的数值为基数，再乘 `(1 + 将印生命%)`。输出型 +2%/级、坦克型 +4%/级、治疗/辅助 +3%/级、被动光环型 +3%/级。
- **兵略**：同样以「基础 100 + 天赋 + 符文」为基数乘 `(1 + 将印兵略%)`。输出型 +3%/级、坦克 +2%/级、治疗/辅助 +3%/级、光环 +2%/级。
- **疾行（第三根基）**：提供**将印冷却通道**缩减（原冷却的 -3%/级）；该通道**不受天赋+符文 50% 合并上限约束**——天赋/符文/将印三通道合计可将最终冷却压至**原冷却的 30%**（绝对下限 2 秒仍生效）；**当该武将已到达 30% 阈值，疾行节点自动改提供行动增速 +4%/级**（玩家亦可主动二选一切换：冷却 or 行动增速）。被动武将（冷却 0）根基三恒为行动增速。

**消耗与预算**：根基 1/级、定位 2/级、绝技 3/级、分歧 4、羁绊 4/级、长青 4/级、将魂 8 → **满树约 51~53 枚**（对比 v0.3 的 33~41）。配合 §4.1 掉落：45 回合远征约产 24 枚/局——满树一名武将约需 2~3 局深度远征专攻，或用通用印并行铺 2~3 棵半树，形成「专精 vs 广度」长期目标。

### 4.4 资源规则

- 点亮默认优先专属、不足补通用；UI 提供「仅专属 / 自动补通用」开关。
- **重置消耗将魂（拍板 #4）**：单树重置费用 = 已投入节点数 × 20 将魂，全额返还两种将印；与天赋树重置同一入口逻辑。
- 免疫/复活/无敌类节点必有限次或冷却；将印效果仅 `team == "player"` 且 **`game_mode == "endless"`** 生效。

### 4.5 生效路径与 UI 对比（★ 拍板 #6）

```
_seal_stat_bonus(hero_id) → 生命%/兵略% 乘区 + 疾行(冷却%或行动增速%)
  → _apply_progression_to_new_unit(unit)（progression_system.gd:464，★ 加 game_mode=="endless" 门槛）
  → 冷却：_unit_skill_cooldown 三通道合并，下限 = max(2.0, 原冷却×30%)
  → 行动增速：_unit_action_gain_multiplier
```

**属性对比预览（新增 UI 硬需求）**：将印面板与备战详情必须显示每名武将的**瀑布式前后对比**：

```
最大生命：基础 4200 → +天赋 320 → +符文 640 → ×将印(1+12%) = 5790（↑8.5%）
兵略值：  100 → +天赋 8 → +符文 12 → ×将印(1+9%) = 130.9
冷却：    5.7s → 天赋/符文 -0.85 → 将印 -0.51 → 4.34s（下限 1.71s = 30%）
行动增速： +8%（疾行转化后）
```

未点亮节点悬停显示「点亮后变化」（灰→亮对比）；闯关模式下同面板标注「将印仅无尽远征生效」并置灰数值。
