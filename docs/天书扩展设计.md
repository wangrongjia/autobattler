# 三国·羁绊战棋 · 天书扩展设计(替换双阵营池 + 规则型新增)

> 本文档在《天书模式设计.md》(48 本)基础上进行扩展:
> 1. 用 6 本「规则改变型」天书**替换**原「双阵营武将池」6 本(汉江盟书/汉魏争锋/汉末逐鹿/曹孙对峙/魏群会猎/江表纳贤),总数保持 48;
> 2. 追加 9 本扩展天书,作为第四批投放,总数可扩至 57。
>
> 原文档不做任何改动;本文档为独立增量方案,暂不实装代码。

---

## 一、设计参考:LoL 强化符文(Augments)的三条精神

参考英雄联盟斗魂竞技场/大乱斗强化符文的核心乐趣,而非照搬具体效果:

| 原则 | 说明 | 反例(避免) |
|------|------|------------|
| **改变规则 > 堆数值** | 天书应让一场战斗"玩起来不一样":时停、传染、召唤、反转惩罚 | 又一本"+X 兵略" |
| **制造抉择** | 有代价、有风险、有上限触发,让玩家权衡 | 无脑必选的白板增益 |
| **构筑幻想** | 让玩家围绕它设计整套阵容与站位 | 与任何体系都不互动的孤立效果 |

原有的双阵营武将池 6 本只是"限定选将范围",交互浅、选与不选缺乏戏剧性,故替换为以下规则型天书。

## 二、替换包:6 本规则型天书(顶替双阵营武将池)

> 与武将池天书共用「互斥槽位」:同一时间只允许一本生效,新选覆盖旧效果(沿用原武将池冲突规则)。这样替换后无需改动候选池结构。

### 1. 武魂复刻(替换·汉江盟书)

| | 效果 |
|---|---|
| 一级 | 从本回合起,每轮武将三选一中,**必定有一张候选是已拥有武将的「武魂」**(同名复刻:独立单位,独立血量/行动条/施法,但**不重复计入阵营羁绊人数**) |
| 二级 | 武魂登场时立即充满行动条,且兵略 +8 |
| 构筑方向 | 复数核心:"双郭嘉冻结流""三关羽劈砍流" |
| 设计意图 | LoL「复制」类 augment 的三国化;羁绊去重规则天然防止滚雪球 |

### 2. 空城疑兵(替换·汉魏争锋)

| | 效果 |
|---|---|
| 一级 | 每场战斗开始时,若我方**上阵武将 ≤5 名**,全体上阵武将兵略 +12%、最大生命 +12% |
| 二级 | 增益提高至 +20%/+20%,且敌方随机一名武将开场行动条 −30 |
| 构筑方向 | 精兵单核、五虎流 |
| 设计意图 | 反直觉规则:奖励"少上阵",改变布阵策略;对应"空城计"以少胜多 |

### 3. 借东风(替换·汉末逐鹿)

| | 效果 |
|---|---|
| 一级 | 每场战斗**第 10 秒**刮起东风:我方全体行动条 +15,并清除我方全体的灼烧与中毒 |
| 二级 | 行动条 +25,东风同时席卷敌方:敌方全体灼烧 2 秒(每秒 15% 我方平均兵略) |
| 构筑方向 | 中场决胜、反毒火 |
| 设计意图 | 定时战场事件,给 30 秒战斗增加"节奏点";赤壁东风主题 |

### 4. 草木皆兵(替换·曹孙对峙)

| | 效果 |
|---|---|
| 一级 | 敌方武将每次施放技能时,**15% 概率被打断**,并压退其行动条 20 |
| 二级 | 概率提高至 25%,被吓退者额外受到一次「惊惧」伤害(80% 我方平均兵略) |
| 构筑方向 | 干扰流、对抗高频施法阵容 |
| 设计意图 | LoL「压制敌方」类;上限是概率,不破坏基本循环 |

### 5. 火攻连环(替换·魏群会猎)

| | 效果 |
|---|---|
| 一级 | 我方施加的灼烧**自然结束时**,向最近的未灼烧敌人传染(继承 50% 时长与每秒伤害) |
| 二级 | 传染继承 100%,且单次施放的灼烧最多可连续传染 3 个目标 |
| 构筑方向 | 周瑜/陆逊/祝融火攻队 |
| 设计意图 | 连锁反应型;注意与「奇门毒典」叠加会非常强,见平衡备注 |

### 6. 天妒英才(替换·江表纳贤)

| | 效果 |
|---|---|
| 一级 | 选择时**立即从备战席随机移除一名武将**(本局),作为交换,其余全体武将兵略 +10、最大生命 +6%;备战席为空时增益减半 |
| 二级 | 改为**可指定**移除一名备战武将,增益提高至兵略 +18、最大生命 +10% |
| 构筑方向 | 高风险高回报的后期质变 |
| 设计意图 | LoL「诅咒/献祭」类 augment;一级随机制造戏剧性,二级给掌控感 |

## 三、扩展包:9 本新增天书(第四批投放)

### 权衡型(代价换强度)

#### 7. 嗜血双刃

| | 效果 |
|---|---|
| 一级 | 全体武将造成伤害 +15%,但受到伤害 +10% |
| 二级 | 造成伤害 +25%,受到伤害仅 +8% |
| 构筑方向 | 极限输出、配合回复/免死体系 |

#### 8. 背水一战

| | 效果 |
|---|---|
| 一级 | 全体最大生命 −10%,兵略 +15,开场行动条 +10 |
| 二级 | 兵略 +25,开场行动条 +20(生命代价不变) |
| 构筑方向 | 先手斩杀,30 秒内结束战斗 |

### 棋盘规则型(改变站位价值)

#### 9. 八阵图

| | 效果 |
|---|---|
| 一级 | 站在**棋盘四个角落**的武将:兵略 +10%、受到伤害 −8% |
| 二级 | 角落增益翻倍;站在**中央列(第 3 列)**的武将技能冷却 −0.2s |
| 构筑方向 | 站位学问拉满,诸葛主题 |

#### 10. 缩地回春

| | 效果 |
|---|---|
| 一级 | 敌军攻击我方**空格**时,不再伤害我方主公,转而为**我方主公恢复 1% 最大生命** |
| 二级 | 恢复 2%,且该次攻击者被「迟滞」(行动条 −10) |
| 构筑方向 | 空阵诱导流——故意留空格骗敌方攻击,反转"空格打主公"惩罚 |

### 事件型(战场节点)

#### 11. 反客为主

| | 效果 |
|---|---|
| 一级 | 每场战斗**前 3 秒**,敌方全体行动条停止增长 |
| 二级 | 延长至前 5 秒,且时停结束时我方全体获得 3 秒 10% 增伤 |
| 构筑方向 | 先手爆发链,配合「先发制人」 |

#### 12. 单刀赴会

| | 效果 |
|---|---|
| 一级 | 战斗开始时,我方兵略最高的武将立即对敌方兵略最高的武将发动突袭(150% 兵略伤害);命中后我方全体伤害 +8%,持续 10 秒 |
| 二级 | 突袭伤害 250%;若直接击杀目标,全体 +15% 增伤持续整场 |
| 构筑方向 | 单核集火、关羽/吕布主题 |

### 召唤型

#### 13. 黄巾召唤

| | 效果 |
|---|---|
| 一级 | 每场战斗开始时,召唤 **2 名黄巾力士**部署到我方前排空位(生命 = 我方平均最大生命 60%,兵略 = 平均兵略 50%,无技能,仅普攻;战斗结束消失,**不占上阵位、不计入阵营羁绊**) |
| 二级 | 召唤 3 名;黄巾力士阵亡时爆炸,对相邻敌人造成 100% 自身兵略伤害 |
| 构筑方向 | 肉盾挡刀、人海战术 |
| 设计意图 | LoL「召唤物」类;注意与「空城疑兵」互斥检查(见备注) |

### 滚雪球型(跨回合)

#### 14. 胜战连捷

| | 效果 |
|---|---|
| 一级 | 每赢下一个回合,下一回合开场我方全体行动条 +8(连胜可叠加;一旦输掉回合全部清零) |
| 二级 | 每层 +12,且连胜期间全体兵略 +3/层 |
| 构筑方向 | 顺风滚雪球,逆风谨慎选择 |

### 反击型

#### 15. 美人离间

| | 效果 |
|---|---|
| 一级 | 敌方武将每次攻击我方**后军**武将时,12% 概率被反噬**魅惑 1 秒** |
| 二级 | 概率 20%,魅惑时长 1.5 秒,且清除目标身上全部增益 |
| 构筑方向 | 后排保护、貂蝉主题 |

## 五、平衡与冲突备注

1. **火攻连环 × 奇门毒典**:灼烧传染 + 持续时间延长叠加后覆盖面极大,建议两者同时持有时,传染继承比例从 50% 递减至 35%(二级 100%→70%)。
2. **空城疑兵 × 黄巾召唤**:黄巾力士是否计入"上阵 ≤5"判定——建议**不计入**(召唤物不占上阵位),否则二级空城与召唤流冲突。
3. **嗜血双刃 × 残阳血战**:增伤叠乘后残血武将易被秒,建议两者增伤同乘区结算,总增伤上限 60%。
4. **缩地回春 × 守土有责**:一本把空格惩罚变增益、一本降低空格惩罚,效果重叠方向一致,允许叠加但主公单次恢复上限 2%。
5. **反客为主 × 先发制人**:开场时停 + 开场行动条等于白拿 3~5 秒,强度偏高,建议反客为主与先发制人同时持有时,时停时长 −1 秒。
6. **天妒英才保底**:至少保留一名武将(备战+上阵共 1 名时不可选此书),避免自灭。
7. **通用限制沿用原文档**:冷却下限 1 秒、同名不三叠、"每场战斗一次"类每回合重置。
