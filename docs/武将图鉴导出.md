# 战三国·弈定九州 · 武将图鉴导出

> 数据基准(与当前代码一致):
> - 生命/冷却/兵种来自 `registered_hero_balance.gd` 的 BASE_STATS(最终生效值)。
> - **冷却为生效值 = 基线表值 × 2.0**(`GLOBAL_SKILL_COOLDOWN_MULTIPLIER`),即游戏内实际读条秒数。
> - 技能描述逐字来自 `game_ui.gd` `_skill_detail`;羁绊效果逐字来自 `_hero_bond_detail`。
> - 技能文案中的控制时长已包含 `CONTROL_DURATION_MULTIPLIER = 1.8` 的换算。
> - 兵略值全员归一为 100,"X% 兵略值"即以 100 为基准换算。
> - 冷却为 0 的武将为被动武将。
