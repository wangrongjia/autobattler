# 三国·羁绊战棋 · 全武将锁敌机制汇总

> 基于当前代码 `combat_system.gd` 各施法函数整理。锁敌机制 = 技能释放时如何选择攻击目标。

---

## 坐标与射程基础

**棋盘坐标**:敌方棋盘 row0=前军、row1=中军、row2=后军,共 3 行 × 5 列 15 格。

**射程档位与可攻击排**(`_attackable_rows`):

| 射程 | 档位含义 | 可攻击的敌方排 |
|------|---------|---------------|
| 1 | 近战 | 仅敌前排 |
| 2 | 中程 | 按自身站位:己前排→敌前中后排;己中排→敌前中排;己后排→仅敌前排 |
| 3 | 远程 | 全部三排 |

**空格处理**:选中的格子无武将时,伤害转为主公(`_hit_ruler`);潜行中的武将视为空格。

## 六、关键设计观察

1. **射程形同虚设**:60 名武将中**只有 8 名**的技能真正受射程限制(关羽、赵云、黄忠、姜维、祝融、带来洞主、太史慈、丁奉),其余全部绕过射程直接全盘选目标。射程主要影响**站位规则**(前军只能放前排等),而非技能射程。

2. **随机为主流**:约 20 名武将用"随机 N 名敌方"模式,是游戏的主流锁敌方式,保证了不确定性。

3. **排限定构成站位博弈**:限定前军/后军的技能,逼迫玩家考虑站位;但中军(row1)几乎不单独作为目标限定。

4. **空格攻击主公**:随机格类技能(黄忠、姜维、周瑜)选中空格时伤害转主公,这意味着"空阵"也有代价。

5. **羁绊改变目标数**:大量羁绊(五子良将、四英杰、曹操双卫等)的核心效果是增加目标数(+1~+4),而非改变选择方式。

6. **无单体爆发锁血**:除马超(血量最低敌人所在列)外,没有"直接锁定血量最低单体"的攻击技能——收割型定位不存在。
