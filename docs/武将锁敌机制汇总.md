# 三国·羁绊战棋 · 全武将锁敌机制汇总

> 与 `ThreeKingdom/systems/combat_system.gd` 同步。敌方棋盘 `row0/row1/row2` 分别为前军、中军、后军，每排 5 格。

## 通用规则

- 攻击型技能默认选择“单元格”，不再只从存活敌军中选择。命中武将时伤害该武将；命中空格时，相同基础伤害直接作用于敌方主公，不使用空击减伤。
- 射程 1 初始可选前军。前军有人时只随机前军格；前军无人时开放前军与中军；前、中军均无人时开放全场。
- 射程 2：武将在前军时可选敌方全场，在中军时只可选前军与中军，在后军时只可选前军；这些站位限制不因排内无人而扩展。
- 射程 3 无论站位都可选择敌方全场。
- 多目标技能从合法区域抽取不重复单元格。控制效果只在单元格中有武将时施加；貂蝉、小乔、张梁等纯控制型技能继续直接选择武将。
- “顺延”不同于通用射程扩展：顺延技能只选择第一个仍有武将的排；若全场无人，则选择最后一排。确定排后仍随机或固定选择该排单元格，因此仍可能命中空格。

## 空格持续状态

- 灼烧空格按原伤害与剩余时间每秒伤害对应主公。武将进入该格时，地面灼烧移除，武将继承剩余持续时间和每秒伤害。
- 中毒空格按当前层数每秒伤害对应主公，随后按技能衰减率减少层数。武将进入该格时，地面毒移除，武将继承剩余层数与衰减率。
- 同一格可存在多份持续效果；转移到武将后按现有灼烧叠加与毒层合并规则处理。
